# HavenStone Realty

Production WordPress real-estate website.

## Architecture

- WordPress is the production CMS and website.
- `wp-content/themes/havenstone` contains the custom theme.
- `wp-content/plugins/havenstone-core` contains property/business functionality.
- GitHub provides version control for custom code.

## Planned modules

Properties, property types, locations, agents, enquiries, viewing requests, testimonials, blog, search/filtering, maps, WhatsApp CTAs, SEO and performance.

## Development

Do not commit WordPress core, uploads, database dumps, secrets or environment-specific configuration.
